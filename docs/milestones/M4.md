# Milestone 4: Sending email

**Status:** built and tested against the IMAP test server and an SMTP test server that can simulate rejections. 70 backend tests pass. The app builds for Android.

## What it does

- **Compose, reply, reply all and forward** from the app. You pick the sending mailbox (From).
  - Replies default to **the mailbox that received the original**. Sending from a different one needs an explicit confirmation.
  - Reply all removes your own addresses.
  - Replies carry `In-Reply-To` and `References`, so they thread correctly for the recipient, and the original is quoted. Forwards include the original message.
- **To / Cc / Bcc.** Addresses are validated, and duplicates across fields are sent once. **Bcc addresses never appear in the message headers**; this is checked in the tests.
- **Protection against exposing recipients:** if more than 10 people would see each other's addresses in To/Cc, the app asks first and offers to move them all to Bcc.
- **Undo send:** for 10 seconds after Send (5–30, set in the admin settings), nothing is submitted. **Undo** cancels it completely. Once the mail server has accepted a message, the app says it cannot be recalled.
- **No duplicate sends:**
  - Each compose screen has one idempotency key, so pressing Send twice or a flaky network creates one message.
  - The message bytes and Message-ID are fixed before the first attempt.
  - Claims in the database mean the API process and the cron job never send the same message twice.
  - Every attempt is recorded *before* the SMTP conversation starts.
- **What a sent message's status means:**
  - **Sent** means the mail server accepted it (SMTP 250). It doesn't mean "delivered to the recipient".
  - **Temporary rejections** (4xx, connection problems before the message was transmitted) retry automatically after 1, 5, 15, 30 and 60 minutes, then stop.
  - **Permanent rejections** (5xx, e.g. "no such user") stop immediately and show the server's reason.
  - **Delivery uncertain:** the connection was lost while the message was being transmitted, or the sending process died mid-send. It's *never* resent automatically. The Outbox asks you to confirm "Send again" and warns that it might arrive twice.
  - **Wrong password at send time:** the mailbox is marked "Password needed" and the message waits in the Outbox for "Try again".
- **Sending limits:** each mailbox has a limit, by default 100 messages per hour and 100 recipients per message, typical for shared hosting. Over the limit, messages wait instead of failing.
- **Sent folder:** after sending, an exact copy is saved in the mailbox's Sent folder on the server. Gmail and Microsoft save it themselves, so it's skipped for them. The original is marked Answered or Forwarded. There's a unified **Sent** view across all mailboxes.
- **Outbox screen:** waiting, retrying, failed, uncertain and paused messages, with **Try again / Send now** and **Discard**.
- **Suspension:** messages waiting to be sent are paused when an account is suspended and stay paused after reactivation until you choose **Send now** or **Discard**. They never go out silently.
- **Admin dashboard:** shows the number of messages that couldn't be sent in the last 24 hours. Content isn't visible to the admin.

## How sending runs

The API sends from its own process right after the undo window. On shared hosting, where idle processes are stopped, the 1-minute cron job (`node dist/cli.js cron`) sends anything that's due. In the worst case a message leaves up to a minute after the undo window. On a VPS, `sync:daemon` checks every few seconds.

## Known limitations

- **No rich text, attachments, signatures, templates, drafts or scheduling** in the composer yet: this is plain text. These come in M6.
- **The undo window is enforced on the server** after the message reaches it. A message composed offline is only queued once the phone is back online (M7).
- **Not tested against real providers.** Some providers rewrite or add headers; please test with your real mailboxes.
- **Microsoft 365 / Outlook mailboxes** still can't be connected (M4b, needs "Sign in with Microsoft").
